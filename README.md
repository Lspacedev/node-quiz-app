# Node - Quiz App

Node quiz app running on terminal

## Installation

1. Clone the repository

```bash
git@github.com:Lspacedev/node-quiz-app.git
```

2. Navigate to the project folder

```bash
cd node-quiz-app
```

3.  Install all dependencies

```bash
npm install
```

4. Run the project

```bash
node index
```

## Usage

1. When timer starts, answer each question by choosing from the given choices
2. After answering press enter.
3. There are 4 questions in total.
4. Each round is 15 seconds long.
